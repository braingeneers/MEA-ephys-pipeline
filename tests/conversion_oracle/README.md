# Independent converter oracle inputs

This test kit generates native Max One and nontrivially routed Max Two acquisitions,
original typed metadata and input-only facts. It never reads converted NWBs to
construct expectations. `canonical.py`, `storage.py` and `artifacts.py` compose the complete native artifact
checker. Full corruption controls and actual caller acceptance remain separate;
successful input validation alone does not establish conversion parity.

Use the pinned public scientific runtime with Python 3.11. Generate outside Git,
then validate with the inputs mounted read-only. These mounts are local test setup.

```bash
image=braingeneers/modular-maxwell-to-nwb@sha256:46871688f9a47e4ba5dc292c2b4fdd428890f19c96778e8ee9857aa31e803e0d
mkdir -p /absolute/test-results
docker run --rm --network none -e PYTHONDONTWRITEBYTECODE=1 \
  -v "$PWD/tests/conversion_oracle:/code:ro" \
  -v /absolute/test-results:/evidence --entrypoint python "$image" \
  /code/inputs.py --output /evidence/inputs
docker run --rm --network none -e PYTHONDONTWRITEBYTECODE=1 \
  -v "$PWD/tests/conversion_oracle:/code:ro" \
  -v /absolute/test-results/inputs:/inputs:ro \
  -v /absolute/test-results:/evidence --entrypoint python "$image" \
  /code/validate_inputs.py --inputs /inputs --report /evidence/input-validation.json
```

The sample formula is evaluated before writing raw HDF5, and expected signal,
clock, mapping and electrode arrays are retained as `.npy`. Both selections have
partial final 200-sample chunks. Every source chunk retains offset/size/filter-mask/
compressed SHA identities. Max Two preserves both stores; selected `well002` links
to `data0001`, with different samples, geometry and length from `well000/data0000`.

Facts preserve original projection bytes and JSON types, signed zero, large
integers, unknown transport metadata and uploaded paths. The authored model has
two cell lines, a construct application and related genetic variant, three cultures,
a protocol, subject, context and two pharmacologies. Both parent cultures share a
biological ID while retaining distinct authored keys, ages, object and reference
identities. Fact schema 2 records the extension's float32 schema declaration
separately from exact binary64 storage: the pinned producer coerces finite numbers
to Python float, and HDMF 6.1.0 preserves that precision. Compare stored dtype and
hexadecimal value exactly while retaining original integer/binary64 JSON encodings.
Schema 1's float32 stored-scalar annotations were incorrect; its raw inputs and
other facts remain valid. Regenerate facts into a new directory rather than editing
old evidence or rounding a converted value for comparison.

`model.nodes` and reference payloads use logical authored keys. UUIDs generated by
conversion cannot replace canonical identity/reference checks. In ndx-cell-culture
1.0.0 `related_cultures` aliases the complete `cell_cultures` collection, including
the recorded culture; `pharmacologies` aliases `pharmacologys`. Preserve those
views without counting them as separate containers or dropping the recorded one.

The electrode contract declares all eight metadata Data payloads, four model
reference vectors and the signal's electrode region. Pinned interface/schema
sources provide default-field semantics; the checker must verify the complete
inventory and physical aliases. Measured UUIDs/file creation times require their
own validity, uniqueness and invocation checks. LINDI 0.4.6's generic-reader numeric
padding limitation remains explicit; validate exact native compressed ranges.

`canonical.py` checks complete native NWB science/model against schema-2 facts.
It checks all samples, timing, exact calibration, electrode columns, 30 canonical
containers, 13 Data payloads, every field, ordered reference targets and physical
aliases. It compares actual object identity separately from valid generated UUIDs.
Pinned schemas map the independent expected fields to physical paths/attributes;
extra objects/attributes outside the schema cache fail. Column order may vary under
NeuroConv's set-based insertion, so exact column membership and the saved
colnames/column/HDF5 bindings are checked together. ISO datetimes use HDMF's ASCII
encoding; ordinary text uses UTF-8.

For each case, provide `output.nwb` in an artifact directory and a JSON invocation
receipt named `<case>.json`. Receipts bind case/source/projection/selected raw path
and contain a successful `convert` phase with `started_at_utc` and `duration_s`;
these bound measured file-creation dates without treating them as authored science.
The report is create-only. Keep inputs, artifacts and receipts read-only:
